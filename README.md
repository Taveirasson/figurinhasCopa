# Figurinhas — Álbum Copa 2026

Aplicativo mobile em React Native para controlar e anotar as figurinhas do álbum da Copa do Mundo 2026.

Principais funcionalidades

- Listar figurinhas por time
- Marcar status: `falta`, `tenho`, `repetida`
- Contabilizar quantas figurinhas você tem, quantas repetidas e quantas faltam
- Ajustar quantidade de repetidas e trocar status diretamente na lista

APK
O arquivo APK gerado está disponível em: `apk/figurinhas.apk` (pasta no repositório).

Desenvolvimento (rápido)

1. Instale dependências:

```bash
npm install
```

2. Inicie o projeto:

```bash
npx expo start
```
